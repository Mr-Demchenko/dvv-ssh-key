# Проект Банковское приложение

## Описание:

Проект Банковское приложение - это веб-приложение на Python для работы с картами и счетами.
Созданы функции кодирования отображения номеров карт и счетов
Создана функция сортировки словарей по дате
Создана функция отбора словарей по полю "state"

## Установка:

1. Клонируйте репозиторий:
```
git clone origin	https://github.com/Mr-Demchenko/dvv-ssh-key.git
```
2. Установите зависимости:

### Модуль `generators.py`

Модуль содержит функции-генераторы для работы с банковскими транзакциями и номерами карт.

#### Фильтрация транзакций по валюте

Функция `filter_by_currency` принимает список транзакций и код валюты, а возвращает итератор с транзакциями в указанной валюте.

#### Получение описаний транзакций

Функция `transaction_descriptions` принимает список транзакций и по очереди возвращает описание каждой операции.

#### Генерация номеров банковских карт

Функция `card_number_generator` принимает начальное и конечное значения диапазона и генерирует номера карт в формате `XXXX XXXX XXXX XXXX`.

# E-commerce Project

## Описание проекта
Проект для управления категориями и товарами в интернет-магазине. Реализованы базовые классы:
- `Product` - представляет товар с ценой и количеством
- `Category` - представляет категорию товаров с автоматическим подсчетом количества категорий и товаров

## Структура проекта
- `src/classes.py` - основные классы
- `tests/` - юнит-тесты
- `data/` - JSON-файлы с данными
